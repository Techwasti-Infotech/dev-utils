🔒 Air-Gapped & Zero Data Leakage Guarantee

Online formatters, JWT decoders, and regex testers can expose production tokens, PII, passwords, and proprietary API payloads to remote 3rd party web servers. DevUtils runs 100% locally on your desktop with sandboxed rendering and no outbound network calls.

Built-in Utilities for Developers & QA (18 Tools)

{} JSON Formatter & Minifier

Prettify, minify, and validate JSON payloads with 2-space or 4-space indentations.

🔑 JWT Token Inspector

Inspect header, payload claims, expiration timestamps, and validity countdown completely offline.

⇄ JSON ↔ CSV Converter

Bi-directional data converter between JSON arrays and CSV spreadsheets.

<> XML Prettifier & Validator

Indent and inspect nested XML documents with syntax checking.

🗄️ SQL Query Beautifier

Standardize SQL keyword capitalization and clause formatting for database queries.

0x Hex ↔ Text Converter

Generate cryptographically strong passwords and secrets with custom symbol and length criteria.

Safe encoders and decoders for UTF-8 Base64, URL query parameters, and HTML entities.

Quick Start: Build from Source

To run or compile locally on Windows, macOS, or Linux:

# 1. Clone the repository
git clone https://github.com/techwasti/dev-utils.git
cd dev-utils

# 2. Install dependencies
npm install

# 3. Run unit tests
npm test

# 4. Start the desktop application
npm start

# 5. Build native installer for your OS
npm run dist
